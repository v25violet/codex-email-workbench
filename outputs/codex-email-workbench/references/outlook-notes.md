# Outlook 连接说明

这些规则建立在当前环境实际提供 Outlook Email 能力的前提上；如果 Outlook 连接器不存在或未连接，应按入口 Skill 的降级规则处理。

- 搜索、读取线程、分类、创建草稿和发送只在用户明确请求且通过发送闸门后执行。Outlook 外发正文按纯文本处理，不要假设 HTML 样式会保留。
- 共享或委派邮箱必须保留准确的邮箱所有者/UPN 标识，并与消息 ID 配对；不能把已登录用户替换成共享邮箱所有者，也不能把共享邮箱发件人含糊写成“我的邮箱”。
- 延迟或定时发送前确认收件人集合、时间戳和时区。若来源线程或收件人身份模糊，先停止并澄清。
- 对邮箱状态写入后，应使用提供商返回的可验证查询复核；不要仅凭一次写入返回值声称标签、分类或发送已完成。
- 多账号批次开始前重新读取当前 profile；如果当前邮箱与计划中的发件邮箱不一致，立即暂停并要求用户在授权页面切换/重新授权。当前连接器没有可靠的隐式 `from` 切换，不要猜测或把另一个地址当作当前邮箱。
- 权限不足、共享邮箱不可访问、账号不匹配或限流时停止；不通过另一个账号或浏览器绕过。
