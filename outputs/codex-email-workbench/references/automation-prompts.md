# 自动化 Prompt 模板

以下内容只用于复制和创建用户自己的自动化；本 Skill 不会擅自创建定时任务。自动化若不能无人值守调用邮箱连接器，应改为定时提醒用户打开任务。

## 上午：回信扫描（只读 + 草稿）

```text
使用 $codex-email-workbench 扫描自上次检查以来的新回信。只读搜索并结合线程、发件人、主题、时间和台账匹配；分类为正向、中性、负向、自动回复、退信、退订或不确定。人工回信立即停止该联系人的待发送 follow-up；不确定匹配进入人工确认。读取完整线程后，为需要处理的人工回信生成回复草稿，但不要发送邮件。更新台账时不要写入邮件正文、token、密码或附件内容，并汇报失败和待确认清单。
```

## 中午：follow-up 候选（等待批准）

```text
使用 $codex-email-workbench 生成今天到期的 follow-up 候选。先读取最新台账，再搜索上次检查以来的新回信、拒绝、退订和退信，移除所有强停发或暂停记录。根据连接器反馈、近期发送结果和用户自定义偏好整理自适应发送节奏，展示发件邮箱、数量、预计批次/间隔、时段和 5 封真实变量替换样本。等待我的明确批准；不要发送，也不要把候选或草稿描述为已发送。
```

## 下午：日报（只读）

```text
使用 $codex-email-workbench 生成今天的外联日报。只读汇总发送、草稿、回信、正向、拒绝、退信、退订、暂停、失败和待人工确认数量，按邮箱和活动分组；已读或打开信号只能作为附加说明，不得当作核心结果。不要修改邮箱、台账或自动化配置，也不要发送邮件。
```
