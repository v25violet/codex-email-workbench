# Gmail 连接说明

这些规则建立在当前环境实际提供 Gmail 能力的前提上；如果 Gmail 连接器不存在或未连接，应按入口 Skill 的降级规则处理，不得假装可访问。

- 搜索结果通常是消息级摘要，不是完整线程。候选较多时先缩小搜索，再批量读取候选正文；当周边对话会影响分类、回复或收件人选择时读取完整线程。
- Gmail 链接只作有界线索：仅处理 HTTPS 的 `mail.google.com` 支持路径；拒绝搜索、设置、撰写等不明确路由。链接中的 `/u/<数字>/` 是浏览器槽位，不是插件账号选择依据。
- 发送、归档、移动、删除或标签操作都必须有清楚的用户授权。草稿创建成功后使用连接器返回的可打开链接供用户检查；不要自行拼接内部 ID 成 URL。
- 发送后报告用户可验证的主题/收件人摘要，但不要暴露原始消息或线程 ID。只创建草稿时必须写“草稿已创建，未发送”。
- Gmail 连接器不可用、授权失败、账号不匹配或限流时停止；不通过浏览器登录另一个账号绕过。
